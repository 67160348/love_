PINK LOVE LETTER 💗

วิธีเปิด:
1. แตกไฟล์ ZIP
2. เปิดไฟล์ index.html ด้วยเบราว์เซอร์
3. รหัสผ่านคือ 010169

ไฟล์ในโฟลเดอร์:
- index.html: โครงสร้างเว็บ
- style.css: รูปแบบและแอนิเมชัน
- script.js: การทำงานของรหัส หัวใจ และข้อความ
- squirrel.svg: ภาพกระรอกน้อยการ์ตูนที่วาดด้วย SVG

หมายเหตุ:
- ฟอนต์ Google Fonts ต้องใช้อินเทอร์เน็ตเพื่อโหลด แต่ถ้าออฟไลน์เว็บยังเปิดได้โดยใช้ฟอนต์สำรอง
- รหัสผ่านในเว็บ static เป็นเพียงการซ่อนหน้าจอ ไม่ใช่ระบบรักษาความปลอดภัยจริง
